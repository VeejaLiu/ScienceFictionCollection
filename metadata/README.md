# 作品元信息

小说正文保留在仓库原有的作者、系列目录中。此目录集中维护作者和作品的展示信息，并通过明确路径绑定正文；Web 构建只读取 JSON 和图片，不批量读取正文。

维护时先区分三类内容：**小说目录、期刊目录、来源与核对记录**。网站目录只使用前两类，来源记录不生成阅读页面。

| 想做什么 | 从哪里开始 |
| --- | --- |
| 增补小说、语言或格式版本 | `authors.json` 查作者 → 其 `booksFile` 指向的作品清单 |
| 增补期刊 | `periodicals.json` 查刊物 → 其 `issuesFile` 指向的分期清单 |
| 更换头像、封面 | `avatars/`、`covers/`，并登记各自的来源记录 |
| 查版本、收录或清理经过 | `acquisition/` |
| 查原作年份依据 | `publication-years/` |

```text
metadata/
  authors.json                    作家注册表，不包含杂志社或期刊
  books/                          各作者的小说与版本目录，文件名使用可读作者slug
    liu-cixin.json                 例：刘慈欣
    arthur-c-clarke.json           例：亚瑟·克拉克
  periodicals.json                期刊注册表，保存刊名、出版机构及分期清单位置
  issues/
    science-fiction-world.json    《科幻世界》各期，文件名使用稳定的可读刊名
  avatars/                        作者或刊物图标及来源记录
  covers/                         封面图片、匹配清单及来源记录
  acquisition/                    收录研究、拆分、清理、兼容性及导入记录
  publication-years/              年份事实核对与历史审计记录
  sync.py                         只根据文件名、路径和大小同步目录
```

作者作品清单统一采用 `books/<作者slug>.json`，期刊分期清单采用 `issues/<刊物slug>.json`；分别由注册表的 `booksFile`、`issuesFile` 明确指定位置，不从数字ID推测文件名。作者专项研究记录也使用可读作者slug，例如 `acquisition/arthur-c-clarke.json` 和 `publication-years/isaac-asimov.json`。

ID保留在文件内容中，用于关联作者、作品、封面和阅读进度；显示名称与元信息文件名不承担身份标识。元信息清单此次改名不改变正文路径、公开阅读slug或作品ID。

记录文件使用小写英文与连字符，独立任务按 `<用途或对象>-YYYY-MM-DD.json` 命名；持续维护的作者专题使用作者slug。本说明和作品的 `textSource` 提供来源记录入口。封面当前命名的适用范围与改进建议见 [封面维护说明](covers/README.md)。


## 作者

`authors.json` 使用 `schemaVersion: 1`，`authors` 中每条记录包含：

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定作者标识，例如 `001`；用于内部关联、阅读进度和作品清单文件名 |
| `slug` | 公开网址标识，例如 `liu-cixin`；全局唯一，姓名翻译变化时保持不变 |
| `directory` | 小说仓库根目录下的作者目录，必须与真实路径完全一致，包含原有空格 |
| `booksFile` | 作者作品清单在 metadata 内的明确路径，例如 `books/liu-cixin.json`；文件内容中的 `authorId` 必须与本作者ID一致 |
| `name` | 默认显示姓名，不包含编号 |
| `names` | 按界面语言标记登记的姓名，如 `zh-CN`、`zh-TW`、`en`、`fr`、`de`、`ru`、`ja`、`ko` |
| `avatar` | 相对于 metadata 目录的头像路径，例如 `avatars/001.webp` |
| `bio` | 可选：按语言保存的简短原创介绍，目前有 `zh-CN` 和 `en`；其他界面语言按规则回退 |
| `sources` | 可选：简介资料来源数组，每条为 `{ "label": "来源名称", "url": "https://…" }` |

第一版按已有作者目录整理了简体中文、繁体中文和英文姓名。其他语言可继续人工补充，Web 会优先使用对应名称；缺少对应名称时使用英文或默认姓名。

头像从 Web 仓库现有图片集中到此目录，仅缩小尺寸并转为 WebP，未重新核查来源。

## 作品

每位作者使用一个 `books/<作者slug>.json`，由 `authors.json` 中的 `booksFile` 绑定；文件中保留 `schemaVersion: 1`、稳定的 `authorId` 和 `books` 数组。

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定作品文件标识；初次登记后应保留，不随展示标题修改 |
| `slug` | 全局唯一的公开网址名称，允许中文，例如 `三体`、`死者代言人-epub`；修改标题时保持不变 |
| `workId` | 稳定作品标识；同一作品的各语言文件和不同格式共用该值。不同改写、删节版可分别登记，避免误配 |
| `path` | 相对于该作者 `directory` 的文件路径，可包含多层系列目录 |
| `title` | 展示标题，可人工完善版本、译本等信息 |
| `format` | `txt`、`md`、`epub` 或 `pdf` |
| `size` | 文件字节数，由同步脚本通过 stat 获取 |
| `language` | 正文语言标记，例如 `zh-CN`；不表示已翻译正文 |
| `series` | 系列分组显示名称，可用 `/` 表示层级 |
| `cover` | 封面路径，例如 `covers/works/liu-cixin/三体/reference-edition.webp；未设置时为 `null` |
| `coverSource` | 可选：封面出处 `{ "label": "Open Library", "url": "https://…" }`，在阅读页提供链接 |
| `coverStyle` | 可选：`full`（默认）展示完整封面；`artwork` 为无文字插画，由页面叠加书名和本地化作者名 |
| `publication` | 可选：创作日期、初刊日期、当前收录版本的年份与出处；字段按已查明事实填写，未确认日期为 `null`，不把创作年当作发表年 |
| `editionNote` | 可选：稿次、网络整理或节写版本的说明及尚待确认的信息 |
| `contentStatus` | 可选：`empty-file` 表示现有文件为空，书目可保留但不能据此认定已核实正文版本 |
| `textSource` | 可选：用户提供文本或原刊扫描的来源、PDF页数、提取与收录日期、文件摘要和核对范围；权利依据另见可选的 `rights` 及来源核查记录 |
| `rights` | 可选：逐份正文的权利判断、适用地域、证据链接及核对日期；`public-domain-US-supported`仅表示有证据支持美国公版，不代表全球公版或权利人授权 |
| `chapterTitleCorrections` | 可选：TXT/Markdown 已人工核对的标题边界数组，每项为 `{ "prefix": "原始标题和紧邻正文的行首", "title": "该行开头实际属于标题的部分" }`；字符与空格须逐字匹配，title 必须是 prefix 的前缀；仅在正文中唯一匹配时生效，不改写原文 |

完整路径为 `作者.directory / 作品.path`。网页使用明确登记的 slug，例如 `/authors/liu-cixin/` 和 `/books/三体/`；内部仍通过稳定 id 关联。slug 允许中文、字母、数字和分隔用的连字符，不通过目录名猜测作者姓名或展示标题。

第一版登记 211 个作品文件，同名作品的不同格式、版本分别保留。6 份作者汇总 Markdown 不计为小说作品；已有空 TXT 记录保留，但不会进入站点地图。

## 期刊与分期

`periodicals.json` 使用 `schemaVersion: 1` 和 `periodicals` 数组。每种刊物登记 `id`、`slug`、`name`、多语言 `names`、`publisher`、正文所在 `directory`、图标 `avatar`，并固定 `kind: "periodical"`。`issuesFile` 明确指向分期清单，例如 `issues/science-fiction-world.json`。

分期清单使用 `periodicalId` 和 `issues`，不再用 `authorId`、`books` 表示期刊。各期继续使用稳定的文件 `id`、`workId`、阅读 `slug` 和 `path`；`contentType` 固定为 `periodical`，`publication.issueYear`、`publication.issueNumber` 分别使用整数年份和期号。排序读取这些数值，不解析标题字符串，也不把第6期直接推测为6月刊。已知出版月份另在来源信息中登记。

网站设有独立“期刊”入口：先按年份从新到旧分组，同一年按期号从小到大排列。整期中的文章保留原作者署名；`publisher` 表示出版机构，不作为全期文章的统一作者。阅读网址与进度ID在本次分类迁移中保持稳定，旧刊物入口仍可访问。

## 维护

```bash
python3 metadata/sync.py --check
python3 metadata/sync.py
```

脚本只扫描文件名和文件大小，不读取小说正文。它会保留已有记录的 id、slug、标题、封面和自定义字段；新增文件根据标题生成初始 slug，同名时附加格式、作者名或序号以区分，之后可以人工编辑。已有 slug 不会因标题修改自动变化；重复或非法 slug 会报错。新增作者须先在 `authors.json` 注册。

移动或改名已有文件时，先修改对应记录的 `path`，保留原 id 和 slug，再执行同步。删除的文件会从同步结果中移除。新增封面请放入 `covers/` 并更新该作品的 `cover`。

《创世纪》的原空文件已于2026年10月19日补入用户提供的37页PDF提取文本，保留原路径、作品ID和slug。文末2002年4月23日为二稿落款，不替代书目所载2004年12期至2005年1期的连载信息；原刊逐字比对仍待完成。2026年10月18日追查记录保留当时“正文未导入”的历史状态，当前收录情况以 `books/liu-cixin.json` 的 `textSource` 和年份核对记录为准。

发表年份核对记录保存在 `publication-years/<作者slug>.json`；[全库逐项核对记录](publication-years/verification.json) 覆盖所有作品文件，列出原年份、采用年份、来源、版本口径和待核原因。中短篇按可核实的初刊年，长篇及文集保留有依据的原文书版年或连载年，并在记录中说明；不把创作、获奖或重印年份自动当作初刊年。未确认的题名、作者归属或改写版本不推测年份，保留原文件名；核对记录不会替代 `books/` 中的稳定 ID、slug 和正文路径。

[全库年份缺失检查](publication-years/audit.json) 记录各作者的作品文件数、文件名年份覆盖情况及无法确认的条目；年份事实核对结论见上述逐项记录。作者汇总 Markdown 单独列为参考资料。

[2026年10月18日追查记录](publication-years/follow-up-2026-10-18.json) 复核上一轮8项疑点，优先使用保存的原帖、作者落款、作者授权年表和早期版本原文。《中国2185》的1989明确为创作年，《烧火工》的2012明确为网络首发年；凡尔纳《2889年一个美国新闻界巨子的一天》按正文特征标为1910年修订版，并分别记录1889年首刊和1891年法文修订。未刊稿和网络整理本的创作年份通过作品 `publication.yearBasis` 与正式发表年份区分，不据此虚构初刊日期。

《被遗忘的世界》已按原作归入柯南·道尔目录；原作《失落的世界》发表于1912年，本地中文节写者、译者及该节写本的发表年仍待考。移动时保留已有文件 ID、workId 和 slug，因此 ID 前缀不一定等于当前作者编号。新增柯南·道尔头像的公版来源及摘要见 [头像来源记录](avatars/sources.json)。

封面按 `covers/works/<作者slug>/<作品名称slug>/<版本>.webp` 整理，期刊封面按 `covers/journals/<刊物slug>/<年份>/issue-<期号>-<版本>.webp` 整理。来源编号与图片摘要保留在清单中。没有实际封面的作品由阅读器即时绘制替代图；旧的未引用示例WebP、SVG及配套生成脚本已清理。网页引用图片统一为metadata内的WebP，头像最长边160像素，封面不超过600×900像素。

Web 项目执行 `pnpm metadata:prepare` 或重新启动、构建后，会同步 metadata 与引用图片。列表和静态构建不需要正文文件；读者打开某本书的阅读页时，浏览器自动从内容仓库加载这一本正文，无需再次点击；目录和构建不会加载正文。新增正文须先推送到小说仓库，原始文件链接才可访问。

作者简介是根据各记录 `sources` 中的作者官网、出版社页面或作协资料重新撰写的简短摘要，不复制整段原文。中文界面优先显示中文简介，其他语言缺省显示英文；可继续补充对应翻译。

## 出版封面整理

`covers/catalog.json` 按稳定作品 ID 记录全部作品的封面检索结果，包括来源链接、ISBN（如可用）、原图摘要和核对状态。`embedded-cover` 来自对应 EPUB 的封面图片，只读取容器目录、OPF 元信息和图片，不读取章节；`reference-cover` 是已核对作者与作品的参考版本封面，不能据此认定与 TXT 的译本、版次相同。未核实的记录继续使用生成式封面，不把合集或改编版封面直接标成独立短篇的封面。

`covers/title-aliases.json` 只用于资料检索，记录已知作品的原文名称，不会替换页面的中文标题。出版封面只压缩尺寸并转为 WebP，原图摘要与压缩后摘要均记录；图片下方仍显示 metadata 中的书名和本地化作者名。逐条出处同时保存在作品 `coverSource` 中。来源记录不代表出版社封面获得了开放许可，也不与代码许可证混为一谈。

## 多语言正文版本

界面语言、作者姓名翻译和小说正文语言分别维护。真正的英文小说文件必须登记 `language: "en"`（或 `en-US` 等），不能只把中文文件改成英文语言标记。翻译版本使用自己的 `id`、`slug`、`path` 和 `language`，并用相同的 `workId` 绑定同一作品。`workId` 是稳定内部标识，不随书名翻译、网址或路径改变；新文件同步时默认将自己的 id 作为 workId，人工关联翻译时再修改 workId。

每个作品按“当前界面语言 → 英文 → 任一存在的其他语言”选择版本；多个其他语言并存时按 metadata 顺序选择一个。目录按 workId 合并展示同一作品，默认优先 TXT/Markdown，避免不同格式重复占据书架。每本书的下方及阅读页保留版本选择控件，可手动切换语言、格式；选择按界面语言和 workId 记在本机。同一语言的 TXT、EPUB 等格式都可保留，默认优先在线可读的 TXT/Markdown，不把格式差异当作不同语言。简体与繁体中文分别选择。阅读页遇到可用的另一语言版本时进入该文件自己的网址，阅读进度始终按具体文件 id 保存；没有翻译时只回退读取真实存在的文件，不自动翻译正文。

EPUB 在线阅读与 TXT/Markdown 一样，仅在读者打开该文件时加载正文；构建不解析 EPUB 章节。当前《火星纪事》EPUB 的 `language` 已按 OPF 与实际章节核对为 `zh-TW`，其余文件的语言仍按各自记录维护。
